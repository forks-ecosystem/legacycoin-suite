# UI Rules & Keyboard Shortcuts (LegacyCoin Explorer)

Зафиксированные требования пользователя к интерфейсу. Соблюдать при любых изменениях.

## Макет
- Жёсткий макет приложения: страничный (внешний) скролл НЕ используется. `body{height:100vh;overflow:hidden}`.
  Единственная скролл-зона — таблица `.tw{flex:1;min-height:0;overflow:auto}` (заголовок заморожен `thead th{position:sticky;top:0}`).
- Первая строка и нижние 2 пустые строки-маркеры (`tr.spacer`, они не подсвечиваются курсором) таблицы всегда достижимы скроллом.
- Выделение «текущей» строки — по клавиатуре ↑/↓ (класс `.sel`, синяя линия `inset 3px 0 0 #3B82F6` слева), НЕ по hover.
- Внешний скролл не нужен, мешает восприятию. Не переключать таблицу на страничный скролл.
- `border-collapse:separate;border-spacing:0` (sticky-заголовок не «едет» на несколько px — нет лишнего горизонт. скролла).
- Мобильные (<800px): обычная прокрутка страницы (отключать жёсткий макет).

## Список или таблица
- после загрузки фокус ввода установить на первом элементе, если не задано запоминнание
- у списка снизу должно быть 2-3 пустые строки, чтобы показать конец страницы и правильно ортаботать скролинг
- не утанавливать размер ширины таблтцы 100%, не надо такого делать
- в конец таблицы добавит три пустые строки нормальной высоты

## Клавиши (глобальный keydown в `footSnip`)
- `1` → Home (`/`)
- `2` → All Blocks (`/blocks`)
- `3` → API для бирж (`/exp-3`): проверка транзакции `/api/tx/{txid}` и баланса `/api/balance/{address}`.
- `↑ / ↓` — перемещение курсора строки по таблице; скролл позиционирует стркоу с запасом ~1.6 высоты строки сверху/снизу (на границах показываются 1–2 строки контекста).
- `Home / End` — первая / последняя строка таблицы.
- `P gUp / P gDn` — переход по страницам All Blocks через `[data-dir="prev|next"]` (внутри таблицы страничный скролл курсора убран).
- `← / →` — сплиттер/панели (в All Blocks для страниц используются `PgUp / PgDn`).
- Навигатор `.pg` в All Blocks — вертикальный справа: стрелки `▲` (новее) и `▼` (старее) на `[data-dir="prev|next"]`, без текстовых подписей.
- `Backspace` — фокус в строку поиска (`.sf input`), с preventDefault (не уходить «назад»).
- `Enter` — открыть карточку блока для выбранной строки (`tbody tr.sel[data-height]`), данные из `/api/block/<height>`.
- `Escape` — если карточка открыта: закрыть карточку; повторно `Escape` — свернуть меню (`.sidebar.collapsed`).
- скролинг должен отрабатывать позиционирование сверху и снизу
  показывать одну-две строки ниже или выше курсора строки на границных позициях
- хорошо, пускай после загрузки первый элемент не получает фокуса - это тоже нормально,
тогда курсор - синяя вертикальная черта должна появиться на заголовке таблицы,
и после нажатия клавиши вниз и аналоичных и клике мышки должна исчезнуть
- при скролинге вверх на верхней границе показывать следующую строку, при фиксированном заголовке две
- в конец таблицы добавит три пустые строки нормальной высоты
- при скролинге вниз на нижней границе показывать следующую строку

## Поиск
- первый Escape очищает поле ввода
- второй Escape возвращает фоку ввода списку

## Карточка блока
- Карточка блока — это панель во фрейме fC (третья панель, сплиттер сохраняется) по адресу `/exp-block/{kod}` (`kod` = Height или Hash выбранной строки). Никаких всплывающих/плавающих окон — от них ушли.
- Открывается по `Enter` на выбранной строке (`tbody tr.sel[data-height]`): `parent.lc('/exp-block/'+<data-height>)`; клики по строкам/ссылкам блока — `parent.lc('/block/...')`. `lf()` — разворот fB на весь экран.
- Три панели: Header (height, hash, time UTC, nBits, nonce, version, merkle root, previous hash), Summary (transactions count, size, reward, confirmations, algorithm, difficulty), Transactions (таблица txid).
- Строки таблиц несут `data-height="{{.Height}}"` и `data-hash="{{.Hash}}"`.
- `/exp-block/` — самостоятельная страница без чужого навбара/футера/редиректов; при недоступности узла отдаётся тёплый кэш, PrevHash берётся из кэша или `GetBlockHash(h-1)`.
- `/block/{kod}` и `/block` — тот же трёхпанельный вид (`Header/Summary/Transactions`), шаблон `expBlock`; `/block` без id показывает новейший блок. `handleBlock` тоже кэш-first (node под rate-limit). Ссылки «← Latest» во фрейме зовут `parent.lf('/exp-1')`, на самостоятельной странице — переход на `/` (`home()`).

## Карточка транзакции / адреса (сервисные страницы)
- `/exp-tx/{txid}` — карточка транзакции во фрейме fC: Header (txid, hash, version, size, block, blockheight, confirmations, time, blocktime), Summary (total output, inputs, outputs), Inputs (prev tx / vout / sequence; coinbase — бейдж), Outputs (n, адреса, value, type). Поля из `RawTransaction` (rpc.go).
- `/exp-address/{address}` — карточка адреса во фрейме fC: Header (address, valid, ismine, isscript, watchonly, pubkey hash), Balance (из `getaddressbalance`, при недоступности — «—»), Transactions (txid / block / time / confs / outputs). Поля из `AddressInfo` + `AddressBalance`.
- Обе страницы — самостоятельные, без чужого навбара/футера; ошибка (не найдено/недействительно) — офлайн-карточка с «← Home».
- Ссылки между карточками идут на верхний уровень: блок → `/block/{height|hash}`, транзакция → `/tx/{txid}`, адрес → `/address/{addr}` (всё `target="_top"`).

## Поиск (#DS → /exp-s, отдельный фрейм) и вектор searchx
- Поиск вынесен в отдельный блок: `<div id="DS"><iframe name="fS" id="fS" class="FS" src="/exp-s"></iframe></div>` (`#DS{top:0;right:40px;width:330px;height:50px;z-index:120}`). Главная страница — без `<input>`, поэтому визирь живёт в основном блоке без конфликта фокуса.
- Вектор поиска — `/searchx` (`handleSearchX`): height → `/exp-block/{h}`, txid → `/exp-tx/{txid}`, 64-hex → `/exp-block/{hash}`, `L…` адрес → `/exp-address/{addr}`, иначе ошибка.
- `exp_s.go` — форма `action="/searchx"`; сабмит перехвачен: `e.preventDefault()`, `top.document.getElementById('fC').src='/searchx?q='+…`. `target="fC"` из iframe НЕ работает — только явная навигация.
- `focusSearch()` во фрейме — фокус ввода; `setSF()` в ex.go её вызывает (Backspace). Escape во фрейме: первый — очистить поле, второй — blur (фокус возвращается списку).

## Визирь (#KNOB в #DD, основной блок)
- Визирь — круг `#KNOB` в основном блоке (не iframe): `#DD{position:fixed;bottom:32px;height:30px;z-index:1000;cursor:ew-resize}` над футером.
- Стойка полосы перетаскивается мышкой по всей ширине: шкала растянута **0–100** (положение круга → `DC.style.left` в %). Жёсткий clamp на границах **0/100, без передёргивания на 50** (не использовать `parseInt(val)||50`: `parseInt("0")` falsy).
- `place(v)=left=v/100*(W-d)`; `fromX(x)=clamp((x-d/2)/(W-d)*100)`; drag: `mousedown/mousemove/mouseup` начинается на `#DD`.
- `setCard(v)` — clamp 0..100, `DC.style.left=v+'%'`, `localStorage['panelPos']=v`, `place(v)`. Одновременно `_v` хранит текущую позицию.
- Стрелки `#TL`/`#TR` — в главном блоке (`top:12px;left:3px`), `onclick="parent.clkHH()"`; переключаются в `setMenu(open)`.
- `clkHH()` (Escape и клик по стрелкам): карточка открыта → закрыть (`DC='100%'`, позиция не сдвигается); иначе свернуть/развернуть сайдбар и `setMenu(...)`.
- `setBB()/setBL()/setBR()` — применить текущую позицию/±1; `lc(url)` — fC.src + повтор позиции; `lf(url)` — fB.src и карточку закрыть.

## Тех-заметки
- Строки таблиц блоков несут `data-height="{{.Height}}"` (для Enter).
- RPC узел под rate-limit: `maxRetries=3`, `retryDelay=250ms`; в `GetRecentBlocks` и в `handleBlocks` (`/blocks`) — break после 2 подряд сбоев (один сбой пропускается); кэш блоков 120s + fallback последнего успешного списка `recentFallback`.
- Тёплые страницы списков блоков не делают RPC-вызовов: `/blocks` (page 1) и `/exp-2` (page 0) берут tip из свежайшего блока кэша (`blocks[0].Height`) и отдают кэш (`cachedRecentBlocks`, TTL 120s) напрямую. Холодный кэш выкачивает 50 блоков ≈ 3–20s (узел рейт-лимитит) — это только первый, редкий заход.
- `blockFromCache`/`prevHashFor` (карточки блока) читают только тёплый кэш (`recentBlocksWarm`), без сетевых вызовов; основной путь — прямой RPC `getblockhash`+`getblock` (быстро).
- Узел отдаёт `Too Many Requests` при перегрузке; не подвешивать страницы.
